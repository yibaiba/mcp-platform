# 术语表

界面统一使用下表左列的说法。右列是旧版本界面、文档或接口里可能还会见到的叫法，意思相同。

| 统一用词                   | 含义                                                                                                                       | 旧叫法 / 接口字段                                                               |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| 连接                       | 平台接入的一个 MCP 服务（含 OpenAPI 导入、内容来源），保存地址或命令和凭证                                                 | MCP 连接、服务账号、connection                                                  |
| 内置服务                   | “添加连接”里预置好的常用服务                                                                                               | 内置连接器、connector preset                                                    |
| 运行位置                   | 连接在哪里运行：**平台服务器**，或 **我的设备**（通过设备连接器）。Pi 桥接是高级选项                                       | 执行适配器、执行位置、平台直连、平台主机、adapter（`direct` / `device` / `pi`） |
| 设备连接器                 | 装在你电脑上的小程序，让平台能调用这台电脑上的工具；只在“设备”相关页面出现                                                 | connector                                                                       |
| 连接方式                   | **远程地址**（Streamable HTTP，旧版 HTTP + SSE）或 **本地命令**（stdio）                                                   | 传输协议、进程模式、transport / mode                                            |
| 英文标识（工具名前缀）     | 客户端里工具名的前半段：`英文标识__工具名`。留空时由连接名称生成，中文名称会退化成 `c` 加连接编号                          | 连接展示前缀、toolPrefix                                                        |
| 在客户端中的名称           | 客户端 `tools/list` 里看到的工具名                                                                                         | exposedName、展示名                                                             |
| Agent                      | 一组权限：允许哪些工具、提示词与资源、Skills、文件；客户端以它的身份接入                                                   | Agent 配置、Profile、profile                                                    |
| Agent 名称                 | Agent 的名字                                                                                                               | 配置名称                                                                        |
| Agent 详情                 | 一个 Agent 的详情页：能用的工具、编辑权限、接入客户端；身份、可申请范围、任务和 ID 在“高级”里                              | 工作空间、workspace                                                             |
| 编辑权限                   | 修改 Agent 能用哪些工具和内容                                                                                              | 分配权限（从连接进入时）                                                        |
| 接入客户端                 | 把 Agent 配进 Cursor、Claude 等客户端                                                                                      | 接入                                                                            |
| 接入密钥                   | 客户端不支持浏览器授权时使用的密钥，只在生成时显示一次                                                                     | Agent key                                                                       |
| 客户端配置（不含密钥）     | 只含地址和密钥占位符的客户端配置                                                                                           | 配置模板（接入面板里）                                                          |
| 批量配置                   | 用声明文件一次创建/更新连接和 Agent（高级功能）                                                                            | 配置模板、manifest                                                              |
| 工具 / 工具列表            | 连接提供的工具；“刷新工具列表”重新向服务读取                                                                               | 工具目录、目录、更新目录、刷新目录                                              |
| 提示词与资源               | MCP 的 Prompts、Resources 及模板，和平台内容库里的内容                                                                     | Prompts 与 Resources、内容库                                                    |
| 文件                       | 上传、工具产出或设备间交接的文件                                                                                           | 产物、artifact                                                                  |
| 扩展包（.mcpb）            | MCPB 格式的打包服务，在“导入”里安装                                                                                        | Bundle、MCPB 扩展包                                                             |
| 测试身份：我自己 / Agent X | 在“工具”页以谁的权限测试                                                                                                   | 管理账号                                                                        |
| 服务授权                   | 在服务方（GitHub、Google 等）登录并授权平台                                                                                | 上游授权                                                                        |
| 用我的账号凭证             | 共享连接时，让对方直接用你的账号凭证调用                                                                                   | 所有者凭证、`credentialMode: owner`                                             |
| 角色：管理员 / 普通用户    | 管理员管理用户、网络与安装源和平台设置；全新部署里第一个注册的账号自动是管理员。在账号菜单和“个人账号”页可以看到自己的角色 | admin / member（`pnpm user:role`）                                              |

接口字段名（如 `profileId`、`adapter`、`/mcp/:profileId`）保持不变，旧客户端和脚本不受影响。
