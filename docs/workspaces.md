# Agent 工作空间、权限与交接

工作空间以 Agent Profile 为单位，集中展示授权、上游身份、连接与执行设备、Skill 版本、任务和产物。平台提供应用权限、凭证与会话隔离；设备上的命令仍使用连接器进程的系统权限。

## 身份与执行位置

每个 Profile 可为每条连接选择身份方式：

| 方式           | 行为                                                        |
| -------------- | ----------------------------------------------------------- |
| 沿用连接身份   | 继续使用连接配置的共享或按凭证隔离方式                      |
| Agent 专属身份 | 同一 Profile 使用稳定的上游绑定，外部入口与 Pi 共用上游账号 |
| 按调用凭证隔离 | 接入密钥、OAuth grant 与 Pi 身份分别绑定上游账号            |

未配置时沿用连接行为。Agent 专属身份不随接入密钥轮换而改变；按调用凭证隔离时，新密钥产生新身份，OAuth access token 刷新仍属于原 grant。上游账号可共享，运行会话继续按入口、客户端能力和任务隔离。

OAuth 使用所选绑定完成授权。HTTP/OpenAPI 可保存对应的 API Key、Basic 或 Bearer 凭证；stdio 仅可覆盖连接明确声明的凭证环境变量，命令、参数和工作目录来自连接。独立身份缺少必需凭证时会明确报错，需要配置后再发现目录或执行。凭证加密保存，不通过 Profile 或常规导出返回明文。

连接决定执行位置。工具选择显示连接、设备和身份归属，同名工具保留独立标识。使用“以此 Agent 检查/发现/测试”检查该 Profile 的实际权限和所选身份。跨设备传文件使用产物与文件传输服务，其他设备不能直接读取源设备的本地路径。

保存身份变化前可查看受影响的任务和会话。切换关闭当前 Profile 的相关执行上下文，不撤销其他 Profile 使用的共享绑定；撤销共享绑定则影响其所有依赖者。旧身份的等待申请和临时授权不能转移到新身份。已派发操作可能无法撤回，调用记录保留实际结果或结果未知状态。

## 长期权限与临时申请

长期授权支持工具、Prompt、Resource、资源模板、Skill 版本与产物。模板授权仅覆盖匹配的 URI；Apps UI 资源与关联工具分别授权，app-only 工具不进入模型工具集。

可申请范围与长期权限单独设置。允许申请只开放申请目录和提交能力，批准前不能执行或读取。工具派发、资源读取、订阅、交互续传、Apps 操作和下载使用相同的有效权限判断。

外部申请绑定当前接入密钥或 OAuth grant，Pi 申请绑定当前任务。用户可批准申请的子集、拒绝或取消。审批前重新核对 Profile 修订、身份与可申请范围；重复审批不会增加授权或延长有效期。默认有效期一小时，可明确修改；任务授权在任务结束、取消或到期时失效，以先发生者为准。

Pi 在申请步骤等待，等待不占用业务工具网络执行超时。批准后更新当前任务工具集并返回审批结果，由模型发起新的业务调用。外部客户端可查询申请状态并刷新目录；支持目录通知的客户端可收到变化通知。审批本身不派发业务调用，也不恢复失败或取消的调用。

到期、撤销、身份变化或凭证撤销后，平台停止依赖该授权的活动。已有长期权限仍有效的活动不受临时授权失效影响。重启会中断原等待任务，使任务授权失效；外部凭证授权保留至原截止时间，不跨凭证转移。

## 任务与诊断

任务详情关联输出检查点、工具调用、交互、Apps、权限申请与产物。调用记录包括 Profile、任务、入口、凭证标识、绑定、连接、设备、关联 ID、耗时与状态，不记录认证秘密。

状态区分上游执行、等待交互、等待授权、取消中、失败及结果未知。页面重连先读取持久快照，再接收增量；单调修订号用于避免旧事件覆盖新状态。进程重启后任务标记中断，App 显示视图结束，不恢复或重放工具。

Elicitation 的接受、拒绝、取消和 URL 打开确认由用户处理，与平台权限审批分开。App 的 `ui/message` 进入用户待发送文本，只有用户发送才触发推理；App 上下文只属于当前 App 和任务。模型配置见 [Pi 配置](pi.md)。

## 用户主动交接

1. 选择源任务、目标 Profile、摘要和产物。摘要由用户填写或编辑，不自动调用模型。
2. 预览目标长期权限、选中内容的来源，以及需要新增的产物临时权限。
3. 保存交接记录，随后单独选择执行或导出。预览不是授权凭证，提交和执行都会重新校验源内容、目标修订与权限。

交接只包含选中摘要和产物，不复制原始会话、凭证或 App 状态。Pi 目标创建新任务；外部目标需选择该 Profile 下的有效接入凭证。外部任务包提供需鉴权的产物入口，不含平台密钥或公开下载令牌。

重复执行同一交接不会生成第二个任务。失败保留真实状态，不自动重试。未配置模型时仍可保存、查看和导出；内置执行会明确返回模型配置要求。新任务与后续调用、产物记录交接来源。

## 并发修改与升级

界面更新携带修订号。发生冲突时重新加载当前配置后再提交，避免覆盖并发修改。旧 Profile 请求省略新增身份或可申请字段时保留已有值。

备份、迁移与回退见 [部署说明](deployment.md)，管理和外部接口见 [API 文档](api.md)。
