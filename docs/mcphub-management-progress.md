# MCPHub 管理能力迁入记录

范围：自建 Prompt/Resource、MCPB 导入、分类结果节选。仅修改 mcp-platform；mcp-manger 为只读参考。使用说明和接口见[内容库、MCPB 与分类节选](mcphub-management.md)。

## 实现

- 内容库：账号内 CRUD、预览、启停、数据库唯一索引、修订冲突、加密内容、稳定内容 ID；复用 Profile 授权和真实 MCP 目录/读取，目录变化通知，拒绝跨账号分享，声明式模板往返。
- MCPB：上传解析与脱敏预览；平台直连、Pi、签名设备通道安装；内容摘要去重与目录完整性校验；独立 argv、配置类型及操作系统校验；显式替换修订、并发操作去重、失败回执、重启结果未知且不重放。本机 Web 保存加密配置并显式启停，替换配置也必须匹配预览修订；桌面入口打开本机管理页。
- 分类节选：保留原文和现有权限，增加 head-tail/auto/json/log/search/diff/text 策略；省略策略保持旧行为，默认关闭，不请求模型，不重放上游。无法安全重新序列化的 JSON 整数保留原文。

新增迁移 0021/0022，不重建已有连接或授权。升级前备份数据库、数据目录与密钥；没有修改业务部署，没有发布 Release。单域名、4300 端口和仅 release.published 发布产物规则保留。

## 本地验证（2026-10-29）

环境：macOS arm64、Node.js 24.17.0、pnpm 10.12.4、隔离 PostgreSQL 17。协议服务、Go 连接器和 MCP 客户端均实际运行；没有模型请求。

- 完整 26 组后端回归 356 项通过，每个进程保留 60 秒硬超时。之后补充 Pi MCPB、旧连接器能力拒绝和内容变更通知专项，单独重验相关分组；另增加 Python 与本机编译的 Go 二进制包实际安装测试。最终精确提交以远程 CI 为准。
- 类型检查、ESLint、生产构建、Go test/vet、无模型 Pi 桥接通过。构建保留既有依赖注释和 chunk 大小提示，没有放宽阈值。
- 六架构 CLI、六架构桌面二进制及七个桌面安装包构建通过。桌面构建现在强制包含本机页面，CI 在 Go 检查前也构建该页面。
- Chrome 浏览器完成内容库 CRUD、模板预览、停用、资源 HTML 按文本处理、节选策略保存；平台 MCPB 预览不执行、敏感信息隐藏、实际安装；本机包保存、实际发现工具和停止。375/390px 没有页面横向溢出，截图位于本机 `.data/management-browser-acceptance/`。
- 原首组包含网络、设备与连接器用例，累计超过 60 秒。按功能拆为 26 组后完整通过，没有延长测试进程时限。
- Go 检查曾与本机页面重建并行，embed 资源短暂不存在导致编译失败；改为资源构建完成后顺序检查，通过。
- 浏览器首次出现一次内容保存 500、一次关闭进程组 EPERM，后续直接服务复现及完整浏览器重跑未再出现，原因尚未确定，不能把后续通过说成已修复这两项。验收脚本另修正了重复匹配隐藏 checkbox 和异步保存等待；本机页面缺少 QueryClient 上下文的问题已修复并重验。

## 验证边界
