# MCPHub 管理能力迁入记录

范围：自建 Prompt/Resource、MCPB 导入、分类结果压缩。仅修改 mcp-platform；mcp-manger 为只读参考。本记录不代表完整计划已经交付。

## 当前实现

先实现独立的分类结果压缩模块。Profile 的 resultPresentation 新增可选 strategy：head-tail、auto、json、log、search、diff、text。省略字段时保持 head-tail，整体仍默认关闭，不需要数据库迁移。字段通过现有 Profile 与声明式模板协议传递。

JSON 保留预算内的顶层样本，日志优先错误及相邻行，搜索保留文件组，diff 保留带文件头的修改块。指定格式不匹配时返回原文并明确说明；auto 无法识别时使用普通文本。标记及读取说明不计入保留字节预算。不执行模型调用。

原文先持久化，结果继续使用原调用身份和当前权限读取；REST 重取复用展示结果，不重新调用上游。媒体、structuredContent、错误和 Apps 的既有行为保留。JSON 中无法安全重新序列化的整数保留原文，避免修改源值。

设计参考 MCPHub 的 src/services/toolResultCompressionService.ts 分类策略；本实现按平台字节预算和原文产物契约独立编写，未移植旧控制器、全局配置或 Token 截断实现。
