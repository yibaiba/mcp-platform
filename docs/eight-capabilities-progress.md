## 第一阶段本地验证

在独立仓库工作区运行冻结依赖安装、类型检查、ESLint、生产构建及 Go test/vet，均通过。`pnpm test` 8 组共 179 项通过，每个后端进程保留 60 秒硬超时。数据库为独立 PostgreSQL 17 容器，不使用已有业务库。

真实 Pi SDK 无模型发现与调用通过。Chrome 检查了真实失败连接的恢复次数、下次时间和错误，以及预算与恢复配置表单；服务恢复后自动重连并显示已连接。Python 双架构镜像、Compose 和冷/热缓存验收仍待本仓库 CI：本机 Docker Hub 返回错误域名的 TLS 证书，未禁用证书验证，也未借用其他仓库的已有镜像作为验收结果。

## 第二阶段本地验证

本阶段同时按用户明确确认升级 HMAC。迁移 `0007` 从本仓库现有 schema 生成；旧账号为普通用户，旧设备需要重新配对，保留设备 ID 与连接引用。升级需要新的独立设备认证加密密钥，并同步升级 Go 连接器。

完整后端回归 14 组、215 项通过；每个进程保持 60 秒硬超时。类型检查、ESLint、生产构建、Go test/vet、六架构连接器构建和真实无模型 Pi 检查通过。测试覆盖两种共享身份、两枚接收者凭证、撤权、账号停用、Go HMAC、Apps、Pi、OIDC 协议、注册关闭、日志分页/清理与管理员订阅撤权。

Chrome 已检查共享入口、调用筛选、真实工具调用的统计与详情、系统日志历史和实时订阅。供应商 SSO、远端设备和 Windows 重配尚未实机联调；容器验收待本仓库 CI。

## 第一、二阶段 CI 验收

[第一阶段](https://github.com/yibaiba/mcp-platform/actions/runs/40714397676)与[第二阶段](https://github.com/yibaiba/mcp-platform/actions/runs/40714693595)在 Node.js 22/24 上通过全部检查，原生 Linux amd64/arm64 镜像构建、源码一致性、单端口 Compose、Python 冷/热缓存及 Go 通道检查通过。PR #1、#2 已合并；镜像和安装包发布任务均按规则跳过，仅 Release 发布会推送产物。

## 第三阶段本地验证

完整后端回归 16 组、237 项通过，保持每个进程 60 秒硬超时。类型检查、ESLint、生产构建通过；迁移 `0008` 从本仓库 schema 生成并在独立数据库应用。新增检查覆盖统一别名、隐藏参数、Apps/Pi 入口、模板精确引用、自动推进、冲突、prune、重复引用合并与待配置导出拒绝。

Chrome 检查模板缺少 secretRef 时显示待配置；配置秘密后无需重新应用，连接和 Profile 自动就绪。目录编辑器正确回显工具别名和隐藏参数。该验证不包含真实供应商授权。

## 第四阶段本地验证

完整后端回归 17 组、260 项通过（每进程 60 秒硬超时），类型检查、ESLint、生产构建及冻结锁文件离线安装通过。新增迁移 `0009` 从本仓库 schema 生成并应用。REST 由真实 OpenAPI 适配器调用，覆盖多轮 form/URL、并发幂等、重复回答、取消、结果加密和当前身份权限复检。

升级实测发现旧版 manifest 缺少新增发现字段；读取持久声明时按版本 schema 补齐默认值，保留逻辑映射和 manifest 版本，新增旧模板无需重应用的回归。浏览器已确认旧模板重启后自动恢复就绪。

保留本仓库工具执行上下文和产物权限；搜索投影使用同一目录，产物类型判断不触发服务唤醒，Token 估算包含最终暴露的产物工具。Chrome 已验证官方 Registry 搜索、版本详情、固定 argv 预览、独立 Embedding 表单和本地 Token 估算；390 像素市场页面无页面横向溢出。

本机 PostgreSQL 17、1536 维合成向量、三次查询的中位数：1 千工具约 2538.7 ms，1 万约 20757.4 ms；初次写入约 10.8 秒和 96.4 秒。包含数据库读取、反序列化、余弦和排序，不含 Embedding 推理及 MCP 目录投影。纯内存五次查询中位数分别约 25.5 ms、33.7 ms。不据此增加硬上限。

最初 Chrome 工具将 Apps 内层文档的 HTTP 200 响应保持在暂停状态，未能完成隔离回归。用户明确允许运行独立 Chrome 的 Playwright 脚本后，完成了下述浏览器验收。SSO、真实 Embedding 供应商和远端物理设备仍未实机联调。

最初 npm 2.11.0 被本机 npm 发布年龄策略拒绝，验收改选已满足该策略的 2.9.1，没有关闭策略。一次 macOS 进程组探测出现 EPERM，后续诊断运行及最终完整运行未复现，原因尚未确定。PyPI 首次依赖编译超过默认 60 秒，后续协议握手失败；验收连接明确配置 120 秒并完整通过，生产默认仍为 60 秒。这些初次失败不计为成功。
