## 第一阶段本地验证

在独立仓库工作区运行冻结依赖安装、类型检查、ESLint、生产构建及 Go test/vet，均通过。`pnpm test` 8 组共 179 项通过，每个后端进程保留 60 秒硬超时。数据库为独立 PostgreSQL 17 容器，不使用已有业务库。

真实 Pi SDK 无模型发现与调用通过。Chrome 检查了真实失败连接的恢复次数、下次时间和错误，以及预算与恢复配置表单；服务恢复后自动重连并显示已连接。Python 双架构镜像、Compose 和冷/热缓存验收仍待本仓库 CI：本机 Docker Hub 返回错误域名的 TLS 证书，未禁用证书验证，也未借用其他仓库的已有镜像作为验收结果。
