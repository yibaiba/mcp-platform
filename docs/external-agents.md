# 外部 Agent 接入与隔离

每个外部 Agent 使用一个 Profile，并配置该 Profile 的 MCP 地址与独立接入密钥或 OAuth grant。平台以实际提交的凭证识别调用方，不采用聊天昵称、Bot 名称或工具参数中的身份声明。

| 示例     | MCP 入口                | 凭证         | Profile 权限           |
| -------- | ----------------------- | ------------ | ---------------------- |
| 资料助手 | `/mcp/<资料Profile-ID>` | 资料助手密钥 | 指定检索工具与资料产物 |
| 运维助手 | `/mcp/<运维Profile-ID>` | 运维助手密钥 | 指定诊断工具           |

密钥只能用于绑定的 Profile，修改 URL 或在参数中加入另一个 Profile ID 不会获得其权限。不同凭证的临时授权分别计算；同一 Profile 下的长期授权仍共享。OAuth access token 刷新保留原 grant 身份。

只向外部 Agent 提供其调用凭证。平台管理登录具有账号管理权限，不能用它来限制某个 Profile；“以 Agent 身份测试”才会执行该 Profile 的实际权限。

## 上游账号与运行会话

Profile 对每个连接分别选择沿用连接身份、Agent 专属身份或按调用凭证隔离。需要两个 Agent 使用不同上游账号时，应选择独立身份并分别配置 OAuth、固定 HTTP 凭证或连接声明的 stdio 凭证变量；默认沿用模式可能继续共享连接账号。

Agent 专属身份跟随 Profile，接入密钥轮换不更换上游身份。按调用凭证隔离则使用各自密钥或 OAuth grant。运行会话还按调用入口、会话及客户端能力区分；共享上游授权不等于共享全部执行上下文。

这是平台的应用权限、凭证与运行会话隔离，不创建独立操作系统账号、容器或文件系统沙箱。若外部宿主让所有 Bots 都能取得所有接入凭证，平台只能识别本次使用的凭证，不能证明实际发起请求的是哪个 Bot。需要严格区分时，宿主必须限制各 Bot 可用的连接和凭证；平台 Profile 不能替代宿主隔离。

## 让模型选对工具

外部工具目录保留原有稳定工具 ID、参数结构、输出结构和元数据，在说明中补充原工具名、连接、执行设备及身份方式。同名工具依然使用不同稳定 ID。服务已有标题会保留，缺少标题时补充工具名与连接名。说明不会包含连接配置中的认证请求头、环境变量或凭证明文。

工具说明里的“运行位置”表示连接在平台服务器上运行，还是在某台设备上通过设备连接器运行。stdio 进程在该位置运行，HTTP/SSE 工具则运行于上游服务，不能据此认为其文件也在那台设备上。云端 Agent 不能直接读取另一台设备的路径。先通过已有文件传输服务形成产物，再在 Agent 里授权这个文件。

## 在对话中读取产物

1. 调用 `platform_artifacts_catalog` 获取当前调用主体已获授权的产物、大小和哈希。
2. 调用 `platform_artifacts_read`，明确指定产物 ID、字节 offset 和 length。文本可选 `encoding: "utf8"`；二进制或跨字符边界的分段使用默认 base64。
3. 大文件可按目录返回的 downloadPath 发起鉴权下载，并校验 SHA-256。下载路径本身不授予访问权限。

可申请范围不等于读取权限。申请获批后，需要发起新的读取；另一份接入密钥不会继承该临时授权。到期、撤销或 Profile 策略变化后重新检查权限。产物读取不启动 Pi 推理，也不要求配置模型。

已授权 OpenAPI 工具生成二进制结果时，平台将产物与读取授权放在同一数据库事务中保存。外部调用的结果授权仅属于产生结果的接入密钥或 OAuth grant，Pi 的结果授权仅属于当前任务；不增加整个 Profile 的长期权限。有效期为生成时起一小时，Pi 任务结束后立即失效；授权可在工作空间撤销。身份绑定或 Profile 修订变化也会使其失效。用户如需长期保留或分享，需另行明确配置产物授权或交接。生成期间主体、配置或绑定失效会明确报错，并清理尚未提交的文件。具备 OpenAPI 工具的 Profile 会预先提供产物读取工具，避免模型在生成后找不到读取入口。

外部权限申请立即返回申请记录、需要管理账号登录的 approvalUrl 和下一步说明；客户端使用 platform_permissions_status 查询决定。批准后刷新目录，再发起新的业务调用。内置 Pi 则在申请步骤等待用户决定。审批链接不携带凭证，也不授予审批权限。

官方 SDK 的新旧 MCP 客户端协议测试不等于实际产品验收。Grok Bot 等客户端的自定义连接入口、凭证可见范围和文件交付能力，应在对应产品中分别验证。
